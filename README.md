# keeptrace

Keep URLs and trace query parts with stable normalization.

**Site:** https://theworker02.github.io/keeptrace/

## Install / run

```bash
git clone https://github.com/theworker02/keeptrace.git
cd keeptrace
node src/cli.js
node --test
```
